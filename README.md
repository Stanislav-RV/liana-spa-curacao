# Liana Spa — Massage Curaçao

Статический сайт массажного салона. Без сборки: открывается двойным кликом
по `index.html` и заливается на любой хостинг как есть.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: hero с видео, о Лиане, фотогалерея, 6 услуг, подарочный сертификат, контакты |
| `book.html`  | Бронирование в 4 шага: услуга → дата и время → контакты → подтверждение |
| `gift.html`  | Заявка на подарочный сертификат в 3 шага |
| `terms.html` | Terms & Conditions (все 9 статей из `Algemene Voorwaarden`, 4 языка) |

## Языки

EN / NL / ES / PAP. Переключатель в шапке и в подвале, выбор запоминается
в `localStorage`, можно открыть сразу нужный язык: `index.html?lang=nl`.

Все тексты живут в двух файлах — **править нужно только их**:

- `js/i18n.js` — весь сайт (133 ключа × 4 языка)
- `js/i18n-terms.js` — Terms & Conditions (9 статей × 4 языка)

## Что где менять

| Задача | Файл |
|---|---|
| Телефон, e-mail, адрес, ссылка на карты | `js/app.js` → объект `SITE` |
| Часы работы и слоты записи | `js/app.js` → `SITE.hours` (0 = понедельник … 6 = воскресенье) |
| Услуги, длительность, цены | `js/app.js` → массив `SERVICES` |
| Названия и описания услуг | `js/i18n.js` → ключи `svc.*` |
| Состав и порядок фотогалереи | `js/app.js` → массив `GALLERY` |
| Цвета и типографика | `css/styles.css` → блок `:root` |

Цены заданы один раз в `SERVICES` и автоматически подставляются на все три
страницы — на главной, в бронировании и в сертификате.

## Формы

Формы бронирования и сертификата **сейчас работают в демо-режиме**: они
проверяют заполнение, показывают экран «спасибо» и пишут заявку в консоль
браузера, но никуда её не отправляют.

Чтобы включить реальную отправку, замените блок с комментарием
`Placeholder submit` на вызов вашего обработчика:

- `js/booking.js` — заявка на запись (объект `payload` уже собран)
- `js/gift.js` — заявка на сертификат

Варианты: WhatsApp-ссылка `https://wa.me/59996920525?text=...`, Formspree,
Web3Forms или собственный endpoint.

## Галерея

Карусель на главной работает в двух режимах:

- **Телефон и планшет** — центральная фотография выделена, соседние по обе
  стороны уменьшены и приглушены. Листается свайпом, точками и тапом по
  боковому фото (оно выезжает в центр). Тап по центральному открывает его
  во весь экран.
- **Десктоп (от 960 px)** — три фотографии в ряд, стрелки вынесены в
  отдельные поля по бокам и не наезжают на снимки.

Режим задаётся в CSS переменной `--per-page` на `.gal__track`, JS её читает —
чтобы поменять раскладку, достаточно правки в `css/styles.css`.

Чтобы поменять состав или порядок — массив `GALLERY` в `js/app.js`.
Достаточно добавить туда имя файла, и он появится и в карусели, и в
полноэкранном просмотре (нужны оба файла: `имя.jpg` и `имя.webp`).

## Адаптив

Три раскладки, все проверены:

| Диапазон | Что меняется |
|---|---|
| до 767 px — телефон | Бургер-меню, hero держит пропорцию 3:4, услуги в одну колонку, календарь над слотами |
| 768–1023 px — планшет | Полное меню в шапке (уплотнённое), фото Лианы рядом с текстом, сертификат и контакты в две колонки, календарь и слоты рядом |
| от 1024 px — десктоп | Полные отступы, затемнение hero смещено влево под текст |

Отдельно учтены «низкие» экраны (планшет в альбомной ориентации, ноутбуки
с невысоким окном) — там hero сжимается, чтобы кнопка не уходила за экран.

## Деплой на Vercel

Репозиторий уже подготовлен: корень репозитория = корень сайта, сборка не нужна.

1. Создайте на GitHub **приватный** репозиторий (на сайте есть фотографии
   клиентов — публичный не стоит).
2. Подключите его и запушьте:

   ```bash
   git remote add origin git@github.com:ВАШ-АККАУНТ/liana-spa-curacao.git
   git push -u origin main
   ```

3. В Vercel: **Add New → Project → Import Git Repository**, выберите репозиторий.
   Framework Preset — **Other**, Build Command и Output Directory оставьте
   пустыми, Root Directory — корень. Deploy.

Дальше каждый `git push` в `main` будет автоматически обновлять сайт.

`vercel.json` уже настраивает годовое кеширование для `/assets` и заголовки
безопасности. `.vercelignore` не пускает на хостинг рабочие файлы
(`README.md`, `logo-full.png`, `icon-512.png`).
